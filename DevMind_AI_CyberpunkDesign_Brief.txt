PROJECT OVERVIEW
----------------
Name:        DevMind AI
Tagline:     Unified Developer Intelligence Platform
Type:        SaaS Web Application (React + Vite frontend)
Purpose:     AI-powered suite of tools for developers, SREs, and DevOps engineers.
             Four core modules powered by GPT-4o for security scanning, workflow
             automation, codebase intelligence, and incident investigation.

Tech Stack (frontend):
  - React 18 + TypeScript
  - Vite (build tool)
  - TailwindCSS (styling)
  - Lucide React (icons)
  - shadcn/ui (component library)
  - React Query (data fetching)
  - Wouter (routing)

================================================================================
SITE STRUCTURE — ALL PAGES
================================================================================

1. DASHBOARD (route: /)
   - Main landing page after login
   - Shows 4 stat cards: Security Scans, Workflows Built, Codebase Projects, Incidents Analyzed
   - Recent Activity feed: list of all scans/analyses across all modules
   - Header with DevMind AI logo and tagline

2. SECURITY SCANNER (route: /security)
   - Input: Code paste area (textarea) for any programming language
   - Output: Enterprise-grade vulnerability report
   - Sub-tabs per vulnerability: Overview | Taint Flow | Attack Scenario | Exploit Payload | Code Fix | OWASP
   - Features:
     * Security Score ring/dial (0–10)
     * Severity badges: Critical / High / Medium / Low / Info
     * Per-vulnerability: CWE ID, OWASP category, attack scenario, exploit payload, code diff
     * 6 tabs per finding
   - Sample code buttons for quick demo

3. WORKFLOW BUILDER (route: /workflows)
   - Input: Natural language workflow description textarea
   - Output: Structured AI-generated workflow pipeline
   - 7 tabs on result: Steps | Logic | Data Flow | Resilience | Security | AI Reasoning | Simulate
   - Features:
     * Color-coded pipeline diagram showing workflow steps
     * Step cards with type badges (trigger / action / condition / notification / transform / integration)
     * Simulate mode to walk through the workflow
   - Sample workflow buttons

4. CODEBASE AI (route: /codebase)
   - Input: GitHub repo URL or paste code
   - Chat-style Q&A interface against an indexed codebase
   - Features:
     * Project metadata card (language, framework, file count)
     * Conversation history with AI responses
     * Source citations / references in answers
     * Code snippet display

5. ROOT CAUSE ANALYZER (route: /analyzer)
   - Input: Error logs, stack traces, Kubernetes events, system metrics (textarea)
   - Output: Full AI SRE investigation report
   - 8 tabs per incident:
     * Root Cause — deep technical explanation, stack trace analysis, user + technical impact, security implications
     * Timeline — chronological failure chain (trigger → failure → cascade → recovery → alert events)
     * Dependencies — service dependency chain showing healthy/degraded/failed nodes
     * Remediation — 5 categories: Immediate, Workaround, Long-term Fix, Rollback, Validation
     * Debug Playbook — shell commands, logs to inspect, metrics, DB queries
     * Prevention — prevention measures + monitoring/alerting recommendations
     * AI Reasoning — how the AI correlated logs to reach its conclusion
     * Postmortem — auto-generated structured incident postmortem
   - Incident header: title, severity badge, incident type, risk score (0–10), confidence meter
   - Primary vs cascading failures panel
   - 3 sample incidents pre-loaded

CYBERPUNK REDESIGN — DESIGN DIRECTION
================================================================================

THEME IDENTITY:
  - Aesthetic references: Cyberpunk 2077, Ghost in the Shell, Blade Runner 2049,
    Tron Legacy, Mr. Robot, Deus Ex
  - Feel: Neon-lit, dystopian tech, high-contrast, glitch effects, scanlines,
    digital decay, hacker terminals, neural networks, neon signs
  - Mood words: Electric. Dangerous. Intelligent. Rogue. Neural. Augmented.

RECOMMENDED CYBERPUNK COLOR PALETTE:

  Background (base):     #050811  — near-black with deep blue tint
  Surface / Card:        #0a0f1a  — dark navy card
  Surface elevated:      #0f1625  — slightly lighter card
  Sidebar background:    #060c15  — darkest panel

  Primary Neon (cyan):   #00f5ff  — electric cyan / holographic blue
  Secondary Neon (pink): #ff0080  — hot magenta / fuchsia neon
  Tertiary (purple):     #7b2fff  — deep violet neon
  Accent (yellow):       #ffe600  — warning yellow neon
  Accent (green):        #39ff14  — toxic neon green (matrix green)

  Text primary:          #e0f4ff  — cold white with blue tint
  Text secondary:        #7ab8d4  — muted cyan
  Text muted:            #3d5a72  — dark slate

  Border / grid lines:   #1a2a3a  — dark teal-blue border
  Glow border (active):  #00f5ff33 — translucent cyan glow

  Severity Critical:     #ff0055  — hot red / neon crimson
  Severity High:         #ff6600  — neon orange
  Severity Medium:       #ffe600  — electric yellow
  Severity Low:          #39ff14  — neon green
  Severity Info:         #00aaff  — digital blue

  Code background:       #040d14  — terminal black
  Code text:             #00f5ff  — cyan terminal text

TYPOGRAPHY:

  Primary font (headings):   "Orbitron" or "Rajdhani" — angular, futuristic
  Secondary font (UI text):  "Share Tech Mono" or "JetBrains Mono" — terminal feel
  Body / descriptions:       "Inter" or "Exo 2" — legible but techy
  Code blocks:               "JetBrains Mono" or "Fira Code" — monospaced

  Font weights:
    Headings: 700–900 (bold to black)
    UI labels: 500–600
    Body: 400
    Code: 400

  Letter spacing:
    Headings: 0.05em to 0.15em (spread out, stencil feel)
    Labels/caps: 0.1em–0.2em
    Code: normal

VISUAL EFFECTS:

  1. GLOW / NEON EFFECTS
     - Neon text glow: text-shadow: 0 0 10px #00f5ff, 0 0 20px #00f5ff88
     - Neon border glow: box-shadow: 0 0 8px #00f5ff44, inset 0 0 8px #00f5ff11
     - Buttons: neon outline with glow on hover, pulsing on active state

  2. SCANLINE OVERLAY
     - Subtle repeating horizontal scanlines at 2–4px gap, 3–8% opacity
     - Apply as ::before pseudo-element or overlay div on key containers

  3. GLITCH EFFECTS
     - Title text glitch on hover: CSS clip-path animation shifting text layers
     - Occasional subtle color channel split (red/blue offset) on headings
     - Use sparingly — on page titles and section headers only

  4. GRID / HUD LINES
     - Background dot grid or line grid (like a circuit board)
     - grid lines at ~30px spacing, 3–5% opacity
     - On sidebar and hero sections

  5. CORNER BRACKETS
     - Replace rounded cards with angular cards using CSS clip-path
     - Or: use corner bracket decorations (top-left and bottom-right corners only)
     - Corner style: ┌─  ─┐  └─  ─┘  using borders or SVG

  6. ANIMATED ELEMENTS
     - Blinking cursor on input placeholders
     - Animated underline/progress on scan/analysis loading states
     - Pulsing neon ring on active elements
     - Scrolling hex/binary text in backgrounds (subtle, 2–4% opacity)
     - Data stream / matrix rain for loading screens

  7. TERMINAL AESTHETIC
     - Input textareas styled as terminal windows (dark bg, monospace, neon cursor)
     - Terminal prompt prefix "$ " or ">" on code inputs
     - Terminal title bars with fake macOS-style dots but in neon colors

================================================================================
ANIMATION GUIDELINES
================================================================================

Global:
  - Transition duration: 150–200ms for interactive elements
  - Easing: ease-out or linear for digital feel

Specific animations:
  - Page transitions: horizontal scanline wipe
  - Card appear: fade-in + slight upward translate (20px → 0)
  - Neon pulse: keyframe animation, opacity oscillates 80%→100%
  - Glitch: keyframe with translateX(±2px) + color split, 0.3s duration, triggered on hover
  - Data stream: scrolling hex text, very slow (30–60s loop), 3% opacity background
  - Scanner line: neon horizontal line scanning vertically during analysis loading

================================================================================
RESPONSIVE BEHAVIOR
================================================================================

Desktop (1280px+):  Sidebar always visible, main content fills rest
Tablet (768–1279px): Sidebar collapses to icon-only strip
Mobile (<768px):     Sidebar hidden, hamburger menu, drawer navigation

Breakpoints to maintain:
  - Stat cards: 4 columns → 2 columns → 1 column
  - Vulnerability tabs: horizontal scroll on small screens
  - Timeline: stays vertical, full width
