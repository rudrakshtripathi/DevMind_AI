🧩 THE 4 MODULES TO BUILD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MODULE 1 — AI Security Scanner
- User pastes code or uploads a file
- AI agent analyzes it for vulnerabilities (SQLi, XSS, secrets, insecure deps, OWASP Top 10)
- Returns: severity score, affected line numbers, explanation of risk, suggested fix with corrected code
- Uses RAG to reference known CVE patterns from a local vector store

MODULE 2 — AI Workflow Builder
- User describes an automation in plain English (e.g. "When a GitHub PR is merged, post a Slack message and update a Notion page")
- AI converts it into an executable pipeline JSON with steps, conditions, API call specs
- Shows a live visual flow diagram of the pipeline
- Optional: execute the pipeline using mock API calls with real-time step logs

MODULE 3 — Codebase Knowledge AI
- User uploads a ZIP of their repo or pastes a GitHub URL
- AI indexes all files, extracts structure (functions, classes, relationships)
- User can ask questions: "Where is payment logic?", "What does processOrder() do?", "How does auth flow?"
- AI answers with file path, line reference, and explanation using RAG over the indexed codebase

MODULE 4 — AI Root Cause Analyzer
- User pastes error logs, stack traces, or system metrics
- AI identifies the probable root cause using pattern matching
- Suggests fixes based on past similar incidents (RAG over an incidents knowledge base)
- Returns: root cause summary, confidence score, affected component, step-by-step remediation

🤖 AI AGENT DESIGN (LangGraph)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Each agent follows this LangGraph state machine pattern:

SecurityAgent:
  nodes: [parse_code → detect_patterns → rag_lookup_cve → 
          llm_analyze → generate_fixes → format_report]
  memory: ConversationBufferMemory (for follow-up questions)
  tools: [code_parser, vector_search, severity_scorer]

WorkflowAgent:
  nodes: [parse_intent → identify_services → build_dag → 
          validate_pipeline → generate_json → create_diagram]
  tools: [api_schema_lookup, dag_validator]

CodebaseAgent:
  nodes: [index_repo → chunk_files → embed_chunks → 
          semantic_search → synthesize_answer]
  memory: Persistent per project in Supabase
  tools: [file_reader, ast_parser, vector_search]

AnalyzerAgent:
  nodes: [parse_logs → extract_patterns → rag_incidents → 
          score_hypotheses → generate_remediation]
  tools: [log_parser, vector_search, confidence_scorer]
